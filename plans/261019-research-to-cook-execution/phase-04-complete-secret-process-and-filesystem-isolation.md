## Risk Assessment
- **TOCTOU/host privileges:** descriptor, realpath, metadata and byte checks reduce observed races but cannot make hostile concurrently writable Windows paths an atomic sandbox. Reject ambiguous evidence; report unsupported platform proof. Tests exercise actual Windows junction behavior where available; unavailable symlink privileges are an explicit coverage limitation, not a passing test. Do not silently replace the security test with lexical assertions.
- **Environment compatibility:** stripping home/config can reveal hidden CLI assumptions. Use owned isolated home/fixed command settings and explicit purpose policy; do not restore broad inheritance. PATH remains trusted-host executable selection, not a guarantee against malicious executables or descendants reading accessible files.
- **Partial copy and equal bytes:** a failed write and an external same-content replacement are not equivalent ownership evidence. Journal atomic staging/identity where possible; otherwise preserve unresolved recovery. There is no portable atomic compare-and-swap guarantee for arbitrary filesystem writers; do not promise preservation against an uncooperative actor racing between the final guard and mutation.
- **Evidence loss versus confidentiality:** security rejection cannot become an empty-diff approval or silently drop a required artifact. Surface typed evidence-required/security outcome without printing prohibited bytes; parent Advisor receives safe omission reason only.
- **Shared files:** phases 2/3/6/9 touch collector/EGC/planner/transport. Serial integration preserves contracts and avoids independent redaction, execution, retry or deployment frameworks.
