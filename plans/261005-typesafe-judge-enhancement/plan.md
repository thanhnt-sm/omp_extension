# Context
The current TypeSafe judge needs to robustly evaluate and repair step-by-step plans generated by less capable AI models. To achieve this, we will research state-of-the-art repo patterns for multi-agent plan validation and red-teaming, synthesize these findings, and apply them to harden the evaluator against hallucinations and logical gaps.

# Approach
1. **External Pattern Research & Synthesis**:
   - Use web search to identify 3-5 open-source repositories implementing LLM plan evaluation, red-teaming, or multi-agent step-by-step validation.
   - Output a detailed comparative analysis and inheritance strategy to `docs/typesafe-judge-research.md`.
2. **Red-Team Vulnerability Assessment**:
   - Execute a security/red-team analysis against `src/plan-evaluator.ts` and `src/cook-expert-judge.ts`.
   - Identify bypasses, prompt injection vulnerabilities, and weak-model logic gaps. Document in `docs/typesafe-red-team-report.md`.
3. **Judge Hardening (Model Triage)**:
   - Update `src/plan-evaluator.ts`: Introduce a `PreEvaluationTriage` layer that runs before main evaluation to assess the plan's structural integrity (missing steps, floating dependencies).
4. **Verification Gate Enhancement (Gate 0)**:
   - Update `src/verification-gate.ts`: Implement a "dumb model" fallback protocol. If validation fails, inject explicit step-by-step remediation instructions rather than returning generic errors.
5. **Multi-Persona Pre-Analysis (`ck:predict` integration)**:
   - Update `typesafe-planner.ts`: Invoke a multi-persona debate (Architect, Security, Performance, UX, Devil's Advocate) as a preliminary check for high-risk plans to catch logical flaws before code is written.

# Critical files & anchors
- `docs/typesafe-judge-research.md`: New file for synthesized research.
- `src/plan-evaluator.ts`: Inject triage logic before the core evaluation loop.
- `src/verification-gate.ts`: Add fallback remediation injection in the verification pipeline.
- `typesafe-planner.ts`: Hook the multi-persona debate into the plan ingestion phase.
